## 📐 Especificaciones Generales

### Formato del Archivo:
```
nombre-archivo.pdf
- Nombres en minúsculas
- Separar palabras con guiones
- Sin espacios ni caracteres especiales
- Ejemplo: programa-fecasam-2026.pdf
```

### Optimización:
- Comprimir imágenes a 150 DPI
- Convertir a formato PDF/A para preservación
- Embeber todas las fuentes
- Incluir marcadores (bookmarks) en PDFs largos
- Habilitar búsqueda de texto

### Metadatos:
Establecer en propiedades del PDF:
- **Título:** Nombre completo del documento
- **Autor:** FECASAM 2026
- **Asunto:** Breve descripción
- **Palabras clave:** FECASAM, alpacas, Macusani, etc.

## 💡 Tips Profesionales

1. **Diseño Consistente:**
   - Usar misma paleta de colores en todos los PDFs
   - Mantener estilo visual unificado
   - Logo en mismo lugar en todos los documentos

2. **Información Actualizada:**
   - Verificar fechas antes de publicar
   - Confirmar horarios con organizadores
   - Validar información de contacto

3. **Versiones:**
   - Mantener número de versión (v1.0, v1.1, etc.)
   - Fechar última actualización
   - Guardar versiones anteriores como backup

4. **Impresión:**
   - Diseñar pensando también en impresión
   - Usar CMYK para impresión (RGB para digital)
   - Dejar sangrado si va a imprenta
