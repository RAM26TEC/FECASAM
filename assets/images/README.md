# 🖼️ Imágenes Requeridas para FECASAM 2026

Esta carpeta debe contener todas las imágenes utilizadas en el sitio web.

## 🔴 RECURSOS CRÍTICOS (Requeridos antes de producción)

### 1. **logo.png**
- **Uso:** Logo principal en el header
- **Especificaciones:**
  - Formato: PNG con transparencia
  - Tamaño recomendado: 500px de ancho
  - Resolución: 72-150 DPI
  - Peso máximo: 50KB
- **Ubicación en el sitio:** Header, footer
- **Colores:** Preferiblemente en tonos marrones (#8B5E3C) según la paleta del sitio

### 2. **logo-light.png**
- **Uso:** Logo para fondos oscuros
- **Especificaciones:**
  - Formato: PNG con transparencia
  - Tamaño recomendado: 500px de ancho
  - Resolución: 72-150 DPI
  - Peso máximo: 50KB
  - Versión en colores claros/blancos

### 3. **favicon.png**
- **Uso:** Icono del sitio en la pestaña del navegador
- **Especificaciones:**
  - Formato: PNG
  - Tamaños necesarios:
    - 32x32 pixels (favicon.png)
    - 192x192 pixels (favicon-192.png)
    - 512x512 pixels (favicon-512.png)
  - Fondo transparente o blanco
  - Diseño simple y reconocible

## 🟡 RECURSOS IMPORTANTES (Recomendados)

## 📋 Checklist de Preparación

Antes de agregar las imágenes al proyecto:

- [ ] Optimizar todas las imágenes (usar TinyPNG, ImageOptim, o similar)
- [ ] Convertir a formato web apropiado (JPG para fotos, PNG para logos)
- [ ] Verificar que los nombres coinciden exactamente con los especificados
- [ ] Comprobar que los tamaños son apropiados
- [ ] Asegurar que tienen buena calidad visual
- [ ] Verificar que no infringen derechos de autor
- [ ] Confirmar que las resoluciones son correctas

## 🛠️ Herramientas Recomendadas

**Para optimizar imágenes:**
- [TinyPNG](https://tinypng.com/) - Compresor PNG/JPG online
- [Squoosh](https://squoosh.app/) - Optimizador de imágenes de Google
- [ImageOptim](https://imageoptim.com/) - App para Mac

**Para crear favicons:**
- [Favicon.io](https://favicon.io/) - Generador de favicons
- [RealFaviconGenerator](https://realfavicongenerator.net/) - Generador completo

**Para redimensionar:**
- [Photopea](https://www.photopea.com/) - Editor online gratuito (similar a Photoshop)
- [GIMP](https://www.gimp.org/) - Editor de imágenes gratuito
